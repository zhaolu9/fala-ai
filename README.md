# Fala aí! — 开口说葡语 / 西语

一个口语入门 App：先学发音结构，再从你最常用的句子学起，配中文谐音、单词气泡、跟读打分、测验。支持葡萄牙语（巴西）和西班牙语（墨西哥）切换。

这份说明是写给**不写代码的人**看的。照着做，就能把它变成一个你自己的、可以分享给任何人的网站。

---

## 这个项目的架构（一句话）

用户的浏览器**永远不直接调用 AI**。所有 AI 请求都先经过你自己的服务器函数（`api/generate.js`）——它藏着 API key，并且是你**永久的控制点**：将来要限流、要额度、要收费，都只改这一个文件，所有用户立即生效。

**现在：付费未开启，人人可用。** 但架构已经为付费留好位置（见 `api/generate.js` 里的 `checkQuota` 函数）。

## 上线三步（大约 20 分钟）

### 第 1 步：把代码放上 GitHub

1. 注册 https://github.com （免费）。
2. 点右上角 `+` → `New repository`，起个名字（比如 `fala-ai`），选 Public，创建。
3. 在这个项目文件夹里，把所有文件上传到那个仓库。
   - 最简单的方式：在仓库页面点 `uploading an existing file`，把本文件夹里的所有文件拖进去，提交。
   - （`node_modules` 不用传，`.gitignore` 已经帮你排除。）

### 第 2 步：申请一个 Anthropic API key

1. 注册 https://console.anthropic.com
2. 在 `API Keys` 页面创建一个 key，复制好（形如 `sk-ant-...`）。
3. **重要**：在 `Billing`（账单）里，给这个 key 设一个每月消费上限（比如先设 10 美金）。这是你的安全阀，最坏情况也就花这么多。

### 第 3 步：用 Vercel 部署

1. 注册 https://vercel.com ，用 GitHub 账号登录。
2. 点 `Add New` → `Project`，选中你刚建的那个 GitHub 仓库，点 Import。
3. 在部署设置里找到 `Environment Variables`（环境变量），加一条：
   - Name：`ANTHROPIC_API_KEY`
   - Value：粘贴你第 2 步复制的 key
   - （可选再加一条 `DAILY_TOTAL_CAP` = `500`，给自己上每日总量保险。）
4. 点 `Deploy`。等一两分钟，你会拿到一个网址，比如 `https://fala-ai-xxxx.vercel.app`。

**完成。** 这个网址就是你可以发给任何人的链接——发音、常用句、数字、跟读、测验、我的句子，全部对所有人可用。

## 花钱与监控

- **正常使用很便宜**：翻译一句话约几分钱人民币。你和几个朋友用，一个月可能就几块钱。
- **两道保险已内置**：`api/generate.js` 里有「每 IP 每分钟限流」防恶意刷量；`DAILY_TOTAL_CAP` 给你上每日总量硬顶。
- **看花了多少**：Anthropic 后台的用量面板能实时看到，也能设消费提醒。

## 将来要加“超额付费”时（现在不用管）

架构已经留好位置，那天你只需要做三件事，**不用重建任何东西**：

1. 接一个数据库（比如 Supabase 免费版）记账：谁、今天用了几句。
2. 加一个简单登录（邮箱或 Google 一键登录），好知道“谁是谁”。
3. 把 `api/generate.js` 里的 `checkQuota()` 函数从「永远放行」改成「查数据库：超过免费额度就返回 402」。前端已经会处理这个返回，弹出“今日额度已用完”。

那时候告诉 Claude，让它帮你把这三块接上即可。

## 本地预览（可选，给想先在自己电脑上看看的人）

需要先装 Node.js（https://nodejs.org）。然后在项目文件夹里：

```
npm install
npm run dev
```

打开终端里显示的本地网址即可预览。（本地预览时 AI 功能需要你把 key 放进 `.env` 文件，见 `.env.example`。）
